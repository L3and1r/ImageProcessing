# Обработка изображений — Задание 2

## Описание

В работе выполняется обработка изображения `sar_1_gray.jpg` в оттенках серого.

1. Изображение было зашумлено с помощью шумов гаусса и постоянного.
2. Протестированы: медианный фильтр, фильтр гаусса, билатериальный фильтр, фильтр нелокальных средних с различными параметрами.
3. Выполнена оценка разных фильтров шума.

## Запуск

```bash
pip install -r requirements.txt jupyterlab
jupyter lab
```

## Зависимости

Все необходимые Python-библиотеки указаны в `requirements.txt`.
